## 确定你的验证方式

为了更方便的账号管理和皮肤管理，本服务器并不支持离线登录。因此，您必须使用本服务器支持的登录方式才能进入服务器。

本服务器使用下列两种登录方式：

- 官方正版登录：适用于拥有 Minecraft Java Edition 正版的玩家

- [LittleSkin](https://littleskin.cn) 外置登录：适用于没有正版，但也希望加入服务器游玩的玩家。

你需要先确定自己适合哪种登录方式，再申请加入服务器。

::: tip

对于 LittleSkin外置登录 的使用方法，你可以参考：[在客户端配置 Yggdrasil 外置登录 | LittleSkin 用户使用手册](https://manual.littlesk.in/yggdrasil/client)

对于使用 [LittleSkin](https://littleskin.cn) 的过程中遇到的问题，你应该先在[LittleSkin 用户使用手册](https://manual.littlesk.in/)寻找答案，再考虑向 LittleSkin 的工作人员或服务器管理员求助。这通常可以节省你很多时间。

:::

入群后你必须遵守群规，群规可能因时期的变化而做出调整，具体群规以群置顶公告为准。
在你遇到问题需要提问时，请务必在自行搜索、思考和尝试解决过后再提问。在提问时，请务必附带上截图和详细描述等相关信息。

## 申请白名单

在加入QQ群之后，你可以根据群内公告置顶的问卷申请白名单。但在申请白名单之前，请确保你已阅读并知晓[游玩准则](/rules)中所提及的服务器规定和游玩规范。

提交白名单申请意味着你同意游玩准则，违反游玩准则的玩家将会受到严厉的处罚。
